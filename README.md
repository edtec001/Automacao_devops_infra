# Automacao DevOps Infra

Laboratório pessoal de Infraestrutura, DevOps, Automação, Redes, IoT e Inteligência Artificial.

Este repositório reúne projetos desenvolvidos e testados em ambiente de laboratório, utilizando máquinas virtuais, containers, automação, monitoramento, bancos de dados e dispositivos IoT.

---

## 🎯 Objetivo

O objetivo deste laboratório é estudar, implementar e documentar tecnologias utilizadas em infraestrutura moderna, DevOps, automação e desenvolvimento de sistemas.

Os projetos são desenvolvidos de forma prática, priorizando:

- Automação de infraestrutura
- Virtualização
- Containers
- Redes
- Administração Linux
- DevOps
- Monitoramento
- IoT
- Python
- Inteligência Artificial
- Bancos de dados
- Integração entre sistemas

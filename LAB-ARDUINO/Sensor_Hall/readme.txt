Basic Instructions - Read Carefully:

------------------------------------


1) Create a folder on your computer called "injetor" and copy all the files contained in the link to it.
IMPORTANT: Do not save in a folder other than the one mentioned, otherwise there will be a compilation error!

2) Open the main sketch "injetor.ino" with the Arduino platform. Opening another sketch will also cause a compilation error.

3) Follow the steps shown in the video.


Thank you very much and success with the assembly!
